# 微電網建置效益試算（線上版・密碼保護）

依「2026新微電網建置效益試算_V3.xlsx」公式改寫的網頁版。業務輸入密碼後填寫欄位，即時算出四種商模結果，可儲存案件、下載 Excel、列印成 PDF、複製提案文字。

- 計算邏輯完全照原 Excel，已逐格比對一致。
- 所有清單與價格（成本、利潤、進價、電價）都**加密**存在 `data.enc.json`，沒有密碼的人即使拿到網址或檔案也看不到內容。

---

## 一、檔案說明

| 檔案 | 用途 | 平常要不要動 |
|---|---|---|
| `index.html` | 網頁主檔 | 不用 |
| `data.enc.json` | **加密後的清單與參數** | 更新清單或換密碼時，換這個檔 |
| `css/app.css` | 外觀 | 不用 |
| `js/engine.js` | 計算引擎（對應 Excel 公式） | 改公式時才動 |
| `js/crypto.js` | 加解密（AES-256-GCM） | 不用 |
| `js/app.js`、`js/admin.js` | 畫面與清單管理 | 不用 |
| `js/store.js` | 資料存取層（之後轉伺服器只改這支） | 轉伺服器時 |
| `js/default-data.js` | 加密資料備份（直接雙擊 index.html 時使用） | 不用 |
| `js/vendor/xlsx.full.min.js` | 匯出 Excel 元件 | 不用 |

> ⚠️ 不要把任何「未加密」的 data.json 上傳到 GitHub。

## 二、建立「私人」儲存庫並開啟網站

### 先知道的兩件事
1. **私人儲存庫要開 GitHub Pages，個人帳號需要付費的 GitHub Pro**（免費帳號只能用公開儲存庫開 Pages）。
2. **就算儲存庫是私人的，GitHub Pages 的網址本身仍是公開的**，任何知道網址的人都打得開頁面。所以真正保護資料的是「密碼加密」，私人儲存庫是用來保護原始碼與修改紀錄。

### 步驟
1. **登入 GitHub** → 右上角頭像 →「Settings」→ 左側「Billing and plans」→ 升級為 **GitHub Pro**。
2. **建立私人儲存庫**：右上角「＋」→「New repository」
   - Owner：選你自己的帳號（個人專案）
   - Repository name：例如 `microgrid-calc`
   - 選 **Private**
   - 按「Create repository」。
3. **上傳檔案**：在新儲存庫頁面點「uploading an existing file」
   - 把解壓縮後資料夾**裡面的所有東西**（`index.html`、`data.enc.json`、`css`、`js`、`README.md`）一起拖進網頁。
   - 上傳後，儲存庫首頁應直接看得到 `index.html`。
   - 按綠色「Commit changes」。
4. **開啟 Pages**：「Settings」→ 左側「Pages」
   - Source：「Deploy from a branch」
   - Branch：`main`、資料夾 `/ (root)` →「Save」。
5. 等 1–2 分鐘，Pages 頁面上方會出現網址：`https://你的帳號.github.io/microgrid-calc/`
6. **確認別人進不去**：用無痕視窗打開網址，應該只看到密碼畫面。

> 不想付費？也可以把儲存庫設成 **Public** 免費開 Pages。資料一樣是加密的，外人只看得到程式碼與密碼畫面，看不到價格。

## 三、密碼

- **初始密碼**另外提供（不寫在檔案裡）。上線後請先依下方「變更密碼」換成你自己的密碼。
- 業務第一次開網頁要輸入密碼；勾「在這台電腦記住 30 天」就不用每次輸入。
- 右上角「登出」會清除這台電腦記住的密碼。
- 密碼建議 10 碼以上、英數混合。**密碼忘記無法找回**，請自己保存一份未加密備份（見第五節）。

### 變更密碼
1. 登入後到「清單管理」→「變更密碼」→ 輸入兩次新密碼 →「變更並下載」。
2. 會自動下載新的 `data.enc.json`。
3. 到 GitHub 儲存庫 →「Add file」→「Upload files」→ 上傳這個檔（取代舊檔）→「Commit changes」。
4. 等 1–2 分鐘後，把新密碼告訴業務。之後舊密碼就失效。

## 四、日常使用

- **試算**：左邊填欄位（`*` 為必填），右邊即時出結果。
- **儲存案件**：存在「這台電腦的瀏覽器」。GitHub 版沒有共用資料庫，換電腦或清除瀏覽資料前請在「案件紀錄」按「匯出全部」備份。
- **下載 Excel／列印存 PDF**：在試算頁上方按鈕。

---

## 五、更新清單（新增元器件、改價格、改電價）

1. 「清單管理」→ 左側選清單 → 直接修改或「＋ 新增一列」（修改會加密暫存在本機）。
2. 按「**下載加密資料檔 data.enc.json**」。
3. GitHub →「Add file」→「Upload files」→ 上傳取代舊檔 →「Commit changes」。
4. 所有人重新整理網頁後生效；你自己回「清單管理」按「捨棄本機修改」。
5. 想留一份自己看得懂的備份：「匯出未加密備份（勿上傳）」，存在自己電腦即可。

> 💡 每年 1 月記得在「效益二：時間電價」新增當年度電價，否則效益二會變成 #N/A 或 0（原 Excel 用 `YEAR(TODAY())` 查表，行為相同）。

## 六、安全性說明

- 加密方式：AES-256-GCM，金鑰由密碼經 PBKDF2-SHA256（25 萬次）推導，解密只在使用者瀏覽器內進行。
- 沒有密碼的人看得到：登入畫面、網頁程式碼（計算公式）。看不到：所有價格、成本、利潤、清單與電價。
- 所有業務共用同一組密碼。要做到「每個人各自帳號、可個別停權」，需要轉到公司伺服器加上登入系統。

---

## 七、之後轉到公司伺服器

- 整個資料夾是純靜態網頁，可直接放到 IIS／Nginx／iPanel 主機。
- 要「清單同步」「共用案件紀錄」「個人帳號」，改寫 `js/store.js`（`loadEnvelopes`、`unlock`、`saveLocalData`、`listCases`、`saveCase`…）改呼叫後端 API（例如原規劃的 `MG_DataCollectReceiver.cpt` 與 `mg_collect_*` 資料表）即可，畫面程式不用改。
